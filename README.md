# Buscador Usuarios GitHub

Buscador de informações de usuários do Github. Meu objetivo ao desenvolver esse projeto é pôr em prática o uso de chamadas de API usando a função fetch do JavaScript.

O projeto está disponível para teste aqui: [Buscador Usuarios Github](https://givanyo.github.io/buscador-usuarios-github/)
